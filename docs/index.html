快速开始

三步启动，本地即可 1v1 实测

# 1. 设置 JWT Secret
export SIGNAL_JWT_SECRET="change-me-to-a-long-random-secret"

# 2. 运行服务
make run

# 3. 打开 Demo — 浏览器访问 http://localhost:8080/demo
#    输入房间 ID 和显示名，新开窗口重复操作即可 1v1 实测

信令流程

从建房间到媒体协商的完整链路

  1. 创建房间 — POST /api/v1/rooms，不指定 ID 时自动生成 UUID
  2. 签发令牌 — POST /api/v1/rooms/{id}/join-token，返回 JWT
  3. 建立连接 — GET /ws/v1?token=<JWT>，WebSocket 握手
  4. 加入房间 — 发送 join 消息，服务端返回 joined（成员列表 + ICE 配置）
  5. 媒体协商 — 与对端交换 offer → answer → trickle
  6. 实时交互 — 自由 chat / mute / leave

API 参考

REST 端点（Base URL /api/v1）与 WebSocket 信令协议

REST 端点

方法路径说明
POST/rooms创建房间
GET/rooms/{id}查询房间
POST/rooms/{id}/join-token签发令牌
GET/ice-serversICE 配置
GET/healthz存活探针
GET/readyz就绪探针
GET/metricsPrometheus 指标

WebSocket 消息

连接 /ws/v1?token=<JWT>，必须先发 join

类型方向说明
join→加入房间
offer↔SDP Offer
answer↔SDP Answer
trickle↔ICE 候选
chat↔文本消息
mute↔静音控制
leave→离开房间

配置

所有配置项通过环境变量设置，零配置文件

变量默认值说明
SIGNAL_JWT_SECRET—JWT 签名密钥（必填）
SIGNAL_ADDR:8080监听地址
SIGNAL_LOG_LEVELinfo日志级别 debug/info/warn/error
SIGNAL_ADMIN_KEY—管理 API 密钥（可选）
SIGNAL_ALLOWED_ORIGINS—Origin 白名单（逗号分隔）
SIGNAL_REDIS_ADDR—Redis 地址，非空即启用多节点
SIGNAL_STUNGoogle STUNSTUN 服务器列表（逗号分隔）
